# ChestXrayPneomoniaCNN
This is a Convolution Neural Network Designed to Detect Pneomonia Currently has a 98% Accuracy. If the confidence is under 85% please do your own analysis.
Meant to be open to all users and hoping to expand into other biomedical neural network analysis. Originally started as a basic image processing network, that was then trained to images of both normal and pnemonia skelatal x-rays.
